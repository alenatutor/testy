Теория · шаг 1

Выпускаем квадрат из-под корня

Если под корнем прячется число, из которого корень извлекается нацело, его можно «выпустить» наружу.

Как это работает:

√72 = √36 · 2 = √36 · √2 = 6√2

36 — точный квадрат, он выходит из-под корня числом 6. Двойка остаётся внутри: нацело корень из неё не извлечь.

🔬 Лаборатория: выпусти квадрат сам

Выбери число, потом нажимай на квадраты, на которые оно делится.

Алгоритм

  1. Найди в числе под корнем наибольший делитель, который является точным квадратом.
  2. Запиши число как «квадрат · остаток».
  3. Корень из квадрата вынеси наружу, остаток оставь под корнем.

Квадраты: 4, 9, 16, 25, 36, 49, 64, 81, 100.

Теория · шаг 2

Число большое — делим по очереди

Если квадрат сразу не виден, проверяй делимость на 4, 9, 25, 36, 49 по очереди.

Пример: √180

√180 = √36 · 5 = 6√5

Не заметил 36? Выносим по шагам — ответ тот же:

√180 = √4 · 45 = 2√45 = 2√9 · 5 = 2 · 3√5 = 6√5

Выносить можно в несколько заходов — пока под корнем не останется квадратов-делителей. Попробуй в лаборатории выше: выбери 180 и начни с 4.

Ловушки

  1. √14 = √(2·7): квадратов-делителей нет — оставляем как есть.
  2. Выносят множитель, а не слагаемое: √(9+16) = √25 = 5, а не 3+4.

Теория · шаг 3

Вынесение с буквами

С буквами работает правило со 2 урока: √(a²) = |a|. Модуль раскрываем по условию.

Пример 1. x ≥ 0

√9x2 = 3|x| = 3x

Пример 2. x < 0

√18x2 = √9 · 2 · x2 = 3|x|√2 = −3x√2

🔎 Проверим подстановкой: почему нужен модуль?

Помни

  1. √(x²) = |x| — всегда с модулем.
  2. Если x ≥ 0: |x| = x.
  3. Если x < 0: |x| = −x.
  4. Для чётной степени модуль не нужен: √(x⁴) = x², ведь x² ≥ 0.

Смотри на условие: при x < 0 модуль меняет знак, при x ≥ 0 просто исчезает.

Теория · шаг 4

Внесение: возвращаем число обратно

Внести множитель — значит сделать обратное: число перед корнем спрятать под корень, возведя его в квадрат.
Нажимай и смотри, как тройка прячется под корень:

    Если перед корнем минус:

    −4√3 = −√16 · 3 = −√48

    Минус под корень не вносим — он остаётся снаружи.

    Алгоритм

    1. Число перед корнем возведи в квадрат.
    2. Умножь на подкоренное число.
    3. Запиши всё под одним корнем.

    Зачем это нужно? Чтобы сравнивать числа: когда всё под корнем, сразу видно, какое больше.

    Теория · шаг 5

    Сравниваем числа с корнями

    Сравнить 3√2 и 2√3 «на глаз» нельзя. Приводим оба числа к одному виду — и сравниваем.

    Способ 1. Вносим множители под корень:

    3√2 = √18,   2√3 = √12;   18 > 12 ⇒ 3√2 > 2√3

    Способ 2. Число тоже прячем под корень:

    5√2 и 7:  5√2 = √50, 7 = √49;   50 > 49 ⇒ 5√2 > 7

    ⚖️ Весы: выбери пару

    Алгоритм

    1. Внеси множители под корень, а обычные числа запиши как корень (7 = √49).
    2. Сравни числа под корнем.
    3. Больше подкоренное число — больше и всё выражение.

    Не получается внести? Оцени число между двумя соседними точными квадратами.

    Теория · шаг 6

    Выстраиваем по порядку

    Расставить числа по возрастанию — значит выстроить их на числовой прямой слева направо. Приём тот же: всё под корень.

    Расставьте: 2√5; 3√2; 4; √19

    2√5 = √20,  3√2 = √18,  4 = √16,  √19

    16 < 18 < 19 < 20  ⇒  4 < 3√2 < √19 < 2√5

    С минусами всё наоборот:

    −√20 < −√18 < −√16

    У отрицательных чисел чем больше число под корнем, тем левее число на прямой.

    Алгоритм

    1. Запиши все числа под корнем (4 = √16).
    2. Расставь подкоренные числа по возрастанию.
    3. Верни числам исходный вид.

    Отрицательные числа: сначала расставь «без минусов», потом поменяй порядок на обратный.
